# LinkedIn para Analistas de Dados com NotebookLM

## Contexto

O LinkedIn é uma das principais plataformas utilizadas por recrutadores para identificar talentos na área de Dados. Um perfil bem estruturado aumenta a visibilidade profissional, fortalece a marca pessoal e amplia as oportunidades de estágio e emprego.

Este caderno temático foi desenvolvido com o apoio do NotebookLM para reunir conhecimentos, boas práticas e estratégias voltadas para a otimização de perfis LinkedIn de profissionais que desejam atuar como Analistas de Dados.

---

## Objetivos

- Entender como estruturar um perfil atrativo para recrutadores.
- Identificar palavras-chave relevantes para a área de Dados.
- Aprender a construir um título profissional eficiente.
- Desenvolver uma seção "Sobre" mais estratégica.
- Compreender a importância do networking e da produção de conteúdo.
- Utilizar IA como ferramenta de apoio ao aprendizado.

# Mini Guia de Estudo

## Resumo

Um perfil LinkedIn eficiente para Analistas de Dados deve comunicar competências técnicas, projetos relevantes, certificações e objetivos profissionais de forma clara e estratégica.

## Glossário

### Headline
Título profissional exibido abaixo do nome.

### Networking
Construção e manutenção de relacionamentos profissionais.

### Personal Branding
Gestão da própria imagem profissional.

### Recrutamento Ativo
Processo no qual recrutadores buscam candidatos diretamente na plataforma.

### Palavra-chave
Termo utilizado para facilitar a localização do perfil em pesquisas.
